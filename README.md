# archinstall
Simple bash script made to make install process of arch easier when reinstalling for the 20th time.

Script will setup a system with packages I deem required.
it's configured for AMD systems & swedish locale.

If you would like to copy my system you can grab my [dotfiles.](https://github.com/wapic/dotfiles/)
dotfiles also include a script to install all the required packages and themes

>[!CAUTION]
>Incorrect usage of this script can and most likely will result in unwanted loss of data!
>Use this script at your own risk!

# Usage:
### 1. Download & run script:
```
curl https://raw.githubusercontent.com/Wapic/archinstall/refs/heads/base-install/archinstall.sh -o archinstall.sh
chmod +x archinstall.sh
./archinstall.sh
```

### 2. Reboot!
and now you're done! simply reboot and start configuring!
